# srvkit
tools and libraraies to build server applications

### 命名规范

* 包名使用小写字母和下划线分隔命名（snake_case)，并使用有意义的缩写；
* 包名要见文知义，避免过于通用的名称（如base, common等）；
* Go源代码文件使用小写字母和下划线分隔命名（snake_case）；
* 结构体、接口、函数和变量名使用驼峰命名法（CamelCase）;
* protobuf协议的字段使用小写字母和下划线分隔命名（snake_case）；
* Git提交使用简洁明了的描述，遵循约定的提交规范（参考`Conventional Commits`）;
